# 0004: 采用终末地重工机能风与画内微拟物质感系统（彻底消除塑料感）

我们决定全面重构全站视觉细节规范，对齐鹰角网络《明日方舟：终末地》与《看门狗2》官方工业设计资产，引入“重工机能冷黑底衬、高能信号黄（#FFE600）、四角定焦角标、亚克力内倒角微光与 CRT 荧光暗角”材质系统，彻底终结单薄扁平的“塑料网页感”。

## Context

现有界面虽然具备了功能结构与三维网格，但在微观材质上存在明显廉价塑料感：字体层级松散、底色是生硬死黑而非工业冷黑、边框是普通 1px 细线缺乏装甲切角构件、缺少工程级定焦框与微型标尺序列号、终端字符缺乏光栅感与荧光辉光、沙盘三维网格缺乏实体投影盘面与光晕沉降。

## Consequences

- 全站色彩基调校准为终末地官方重工规范：主信号黄使用 `#FFE600`，基底采用深炭冷黑 `#0C0E12` / `#14171D` 配合微弱网点基质，废除生硬死黑。
- 引入机能工业卡片外壳：所有按钮与视窗必须配备 45° 切削角、四角 L 型定焦框（`⌜ ⌝`）、警戒斜条纹（Hazard Stripes）与内边缘高光反光线（`inset 0 1px 0 rgba(255,255,255,0.12)`）。
- 控制台注入 CRT 硬件质感：注入水平超细荧光扫描线、微透镜暗角暗化（Vignette）以及文字微辉光（Phosphor Text Glow）。
- 沙盘中心 3D 渲染台面增加实体深色半透盘面基底、双环同心刻度圈与信标地表光晕投影。
