# 0005: 采用内联光标锚定与三段式波动自检（清屏后展开徽标）

我们决定将隐藏输入捕获元素就地锚定于活动提示符位置并启用 `focus({ preventScroll: true })`，根治击键与点击导致视窗回滚到首行的严重缺陷；同时将底层硬件自检日志重构为“慢 ➔ 快 ➔ 慢”真实程序波动律动，并在自检结束时执行清屏，随后在纯净界面展开徽标与登录提示。

## Context

原实现将隐藏的 `<input>` 元素放置在 `-top-[9999px]` 的视口负坐标区域。当用户使用鼠标点击终端或在键盘上输入任意字符触发浏览器的焦点管理时，浏览器默认机制强制滚动父容器以试图将该输入框带入视窗，导致整个终端被强行顶回首行（`scrollTop = 0`），彻底遮挡底部的当前命令行。另外，160 行自检以机械固定高速喷出过于单调，且自检文本与徽标堆叠在一起造成视觉杂乱。

## Consequences

- 隐藏 `<input>` 移动至活动输入行容器内部（`position: absolute; opacity: 0; width: 0; height: 0`），并通过 `inputRef.current?.focus({ preventScroll: true })` 彻底剥离浏览器的默认自动滚动行为，确保视窗永远锁定在最后一行。
- 160 行硬件 POST 自检实施三段式变速：初期 CPU/BIOS 阶段（45ms~75ms 慢速）、中期 100 行内存/总线/AIC 网络（8ms~14ms 狂飙飞流）、末期 GPU/着色器编译与安全握手（50ms~90ms 减速稳重）。
- 自检结束输出 `[ALL SUBSYSTEMS NOMINAL]` 后停顿 0.35 秒，自动触发物理清屏（`clear`），接着在干净整洁的视窗中央展开高亮大尺寸 ASCII 徽标与操作员登录提示符。
