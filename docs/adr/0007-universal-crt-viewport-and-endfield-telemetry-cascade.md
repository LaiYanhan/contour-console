# 0007: 采用全局统一视口级 CRT 物理监视器滤镜与终末地 AIC 工业拓扑数据瀑布流

我们决定将 CRT 光栅扫描线（Scanlines）与凸透镜暗角（Vignette）提升至全站顶层视口容器，使终端、全息沙盘与战术视窗均在同一层物理监视器玻璃质感下统一渲染，彻底消除切出终端后的质感断层；同时彻底弃用黑客帝国式经典绿色日文假名雨，重构为具有自主辨识度的“终末地 AIC 工业拓扑数据流（AIC Telemetry Cascade）”。

## Context

用户反馈终端界面质感满意，但切入全息沙盘（Holotable）后感觉不满意、缺少相同质感。技术复盘发现：CRT 扫描线与暗角滤镜此前仅被注入在 `BootTerminal.tsx` 中，一旦切入 Holotable 或二级页面，屏幕质感瞬间跌落为常规网页，破坏了“全程操控一台重型军工战术终端监视器”的沉浸式连续性。另外，此前的代码瀑布过于直白地模仿了电影《黑客帝国》（经典绿色日文片假名），与项目既有的《明日方舟：终末地》工业机能风（Hazard Lemon Yellow #FFE600、Data Cyan #00E5FF、电路符号、十六进制拓扑）发生美学脱节。

## Consequences

- CRT 光栅与光学透镜暗角移至根级 `TacticalApp.tsx`（`fixed inset-0 pointer-events-none z-30`），全局所有视窗与 3D 沙盘均获得相同的实体工业硬件监视器质感。
- 代码瀑布组件 `MatrixRain.tsx` 彻底剔除片假名与单一墨绿色，全面升级为《终末地》专属 AIC 拓扑瀑布流：
  - 字符集采用十六进制机器码（`0-9`, `A-F`, `0x4F`, `0xA2`）、拓扑电路图元（`═`, `║`, `╬`, `┼`, `░`, `▒`, `▓`）与工程序列号（`AIC-04`, `VALLEY-4`, `[OK]`, `//`）。
  - 色彩采用终末地高能信号黄（#FFE600）领头辉光、数据青蓝（#00E5FF）深空数据流与工业暖橙尾迹，辅以周期性水平扫描激光波束，形成极具辨识度的工业机能黑客美学。
