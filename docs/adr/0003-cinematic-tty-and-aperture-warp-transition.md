# 0003: 采用真实内联 TTY 流式交互与 CRT 光轴坍缩转场机制

我们决定彻底弃用类似即时通讯（IM）的底部固定输入栏设计，全面采用真实操作系统标准 TTY 字符流渲染模式，并在控制台切入终末地全息沙盘时引入“深度代码瀑布过载（5倍时长） ➔ 无缝光轴坍缩 ➔ 全息标尺展开 ➔ 3D沙盘升起”，并在逆向返回时采用专用的非对称字符画解构切回机制。

## Context

原先将输入框置于屏幕底部的做法破坏了终端的极客感，使其形似聊天软件而非工业操作控制台；同时页面状态切换缺乏视效过渡，割裂了黑客底层指令与终末地全息沙盘的美学衔接。用户要求开屏具备逐行流式喷吐日志与图标打印特效、完全拟真的就地单行敲击体验，以及具有冲击力的全屏转场动画。

## Consequences

- 终端交互模型重构为纯单流缓冲（Single-stream Buffer）：提示符、输入文字与光标紧贴在最后一行输出正下方，按下回车后固化为只读历史行，所有命令输出均继承逐行电传喷吐动效。
- Tab 补全遵循 Bash / Readline 规范的最长公共前缀（LCP）逻辑，并支持文本光标划词选取与剪贴板复制。
- 跃迁转场引入 5 倍延长的沉浸式代码瀑布流（Matrix Digital Rain，~3.5s）：在 CRT 激光坍缩前维持连贯的代码倾泻，直接从瀑布收拢为激光线，杜绝闪回终端界面；从沙盘返回终端时采用轻量字符画解构逆向展开，避免全套重复。
- 开屏自检日志扩展 10 倍（70+ 行硬件级底层 POST 诊断），以极高速数据率喷吐，营造真实的工业冷启动沉浸感。
- CRT 扫描线与暗角层升级为固态视口挂载（Fixed Screenplate），杜绝内容滚动时的光影断层；光标升级为 500ms 方波瞬断开闭。
