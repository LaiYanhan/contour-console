# 0003: 采用真实内联 TTY 流式交互与 CRT 光轴坍缩转场机制

我们决定彻底弃用类似即时通讯（IM）的底部固定输入栏设计，全面采用真实操作系统标准 TTY 字符流渲染模式，并在控制台切入终末地全息沙盘时引入“黑客代码瀑布预载 ➔ CRT 光轴坍缩 ➔ 全息标尺展开 ➔ 3D沙盘升起”四阶段复合转场状态机。

## Context

原先将输入框置于屏幕底部的做法破坏了终端的极客感，使其形似聊天软件而非工业操作控制台；同时页面状态切换缺乏视效过渡，割裂了黑客底层指令与终末地全息沙盘的美学衔接。用户要求开屏具备逐行流式喷吐日志与图标打印特效、完全拟真的就地单行敲击体验，以及具有冲击力的全屏转场动画。

## Consequences

- 终端交互模型重构为纯单流缓冲（Single-stream Buffer）：提示符、输入文字与光标紧贴在最后一行输出正下方，按下回车后固化为只读历史行，所有命令输出均继承逐行电传喷吐动效。
- Tab 补全遵循 Bash / Readline 规范的最长公共前缀（LCP）逻辑，并支持文本光标划词选取与剪贴板复制。
- 跃迁转场引入前置代码瀑布流（Matrix Digital Rain）：在 CRT 坍缩前插入高频日志喷涌与垂直绿/金字符雨，增强过载侵入感。
