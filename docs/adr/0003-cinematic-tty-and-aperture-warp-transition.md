# 0003: 采用真实内联 TTY 流式交互与 CRT 光轴坍缩转场机制

我们决定彻底弃用类似即时通讯（IM）的底部固定输入栏设计，全面采用真实操作系统标准 TTY 字符流渲染模式，并在控制台切入终末地全息沙盘时引入三阶段“CRT 光轴坍缩与全息标尺展开”电影级转场状态机。

## Context

原先将输入框置于屏幕底部的做法破坏了终端的极客感，使其形似聊天软件而非工业操作控制台；同时页面状态切换缺乏视效过渡，割裂了黑客底层指令与终末地全息沙盘的美学衔接。用户要求开屏具备逐行流式喷吐日志与图标打印特效、完全拟真的就地单行敲击体验，以及具有冲击力的全屏转场动画。

## Consequences

- 终端交互模型重构为纯单流缓冲（Single-stream Buffer）：提示符、输入文字与光标紧贴在最后一行输出正下方，按下回车后固化为只读历史行并在其下一行无缝激活新提示符。
- 开屏引入计时器控制的 Teleprinter 逐行流式输出与 ASCII 徽标自顶向下逐行擦除展开，配备随时按任意键或点击速推的防打扰机制。
- 引入独立的 `TransitionWarp` 转场层：截获指令后，先执行 CRT 垂直光束压缩与扫描线过载闪烁，随后激光束在中央裂解并向四周沿径向炸开终末地 CAD 坐标轴与雷达圈，最后沙盘地形自地平线平滑升起。
