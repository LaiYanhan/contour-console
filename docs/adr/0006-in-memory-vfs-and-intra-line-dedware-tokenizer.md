# 0006: 采用纯前端内存虚拟文件系统（VFS）与行内多色 Dedware 分词着色器

我们决定引入纯前端内存层树状虚拟文件系统（VFS）以承载后续解密小游戏与剧情线索检索，支持 `ls`、`cd`、`cat`、`pwd`、`mkdir`、`touch`、`rm` 以及轻量终端内置 `vim` 查看器；同时重构终端字符流为行内多色 Tokenizer 架构，1:1 还原《看门狗2》官方 Dedware 引导界面的富文本配色规范。

## Context

用户要求终端能够支持查看各种文本文件、进出文件夹、运行常用 Linux 指令，并作为解密小游戏的探索工具。由于部署于 GitHub Pages 静态环境且为临时账号，系统不能也不需要依赖后端数据库；所有文件初始内容应通过项目源码中的模板目录/文件树统一配置，用户登录后自动在 `/home/<username>/` 初始化。此外，原终端单行文本仅能使用单一颜色，无法复现《看门狗2》官方中文引导界面中“同一行内状态词翠绿、设备名浅青、内存地址金色、说明文字哑白”的精细工业美学。

## Consequences

- 终端行渲染模型升级为分词流（Token Stream）：支持单行混排任意数量的色彩片段（如 `[时间戳] 状态: [Ok] 设备 (sda1)` 分别渲染为暗灰、白、翠绿、浅青）。
- 实现轻量纯前端 `VirtualFileSystem`：
  - 维护内存树结构，通过会话存储（SessionStorage）维持生命周期，清除缓存即重置。
  - 项目根目录配置 `src/vfs/initialVfs.ts` 模板字典，后续开发者可直接在该文件中新增任意剧情文本、代码彩蛋与解密关卡文件，自动注入到每个新用户的专属目录。
  - 终端提示符与当前活动路径实时动态联动（如 `dedsec00@talos:~/logs$ `）。
- 终端内置 `VimModal` 查看器：运行 `vim <file>` 或 `cat <file>` 可在终端沙盒内直接查阅多行线索文件，按下 `:q` 或 `Esc` 平滑返回。
